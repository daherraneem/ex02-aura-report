## 3. Findings (most severe first)

**LG-01 · critical** — **Problem:** The deliverable PDF is not in the repository. `/main.pdf` is git-ignored, and no commit contains it, so a grader who clones the repo has no report. **Where:** `.gitignore` (project section, `/main.pdf`); `git ls-files` lists only figure PDFs. **Concrete fix:** After the last fix round, run a full `.\build.ps1` and force-add the final PDF once (`git add -f main.pdf`), or remove the ignore line just before submission. Link it from the top of `README.md`.

**LG-02 · major** — **Problem:** The prompt log is not fully verbatim. (a) `prompts/03-gemini-consult.md` holds Gemini's *answer*, not the prompt Raghad wrote to Gemini, so that prompt is missing. Its "What the agent did" section also describes Antigravity's later work, not Gemini's. (b) `prompts/04-market-chapter.md` admits that the wrapper "was pasted multiple times… recorded once", so it is an edited version, not the verbatim text. (c) `prompts/05-status-check.md` was logged one session late, which is disclosed. **Where:** `prompts/03`, `prompts/04`, `prompts/05`. **Concrete fix:** Add Raghad's actual Gemini prompt(s) to file 03, with the brief kept as an attachment section. In file 04, paste the exact text as sent, including the repetitions, or state precisely what was removed. Keep the late-logging note.

**LG-03 · major** — **Problem:** There are gaps in Raghad's prompts. Her agent "committed and pushed after user approval" (prompts 04, 07, 12, 13) and produced a merge commit (`799018b`, conflict resolution and renumbering), but none of those approval or merge prompts is logged. Raneem logs the same kind of prompt ("approved and push" = 11, "push" = 15). So the "every prompt" rule is applied unevenly between the partners, and a grader cannot reconstruct Raghad's session. **Where:** `prompts/` (no files for Raghad's push approvals or the merge); `git show 799018b`. **Concrete fix:** Recover the missing prompts from the Antigravity history and add them. Adding them at the end with new numbers (16+) avoids renumbering; each new file should state which earlier session it belongs to. If a prompt cannot be recovered, say so explicitly in the file of the session it belongs to.

**LG-04 · major** — **Problem:** Text runs outside the margins, which the booklet's sign-off list forbids. `main.log` shows 36 overfull boxes. Visible examples: ref [44] URL (≈105 pt into the margin), [28] DOI, [5] URL; LOF entry 4.2 (≈55 pt). The reference list alone produces 18 overfull lines. **Where:** `main.pdf` p. 5 (LOF), body pp. 38, 41, 42; `main.log` l. 1885, 2692–2867. **Concrete fix:** In the class, allow URL breaks everywhere (`\setcounter{biburlnumpenalty}{100}`, `biburlucpenalty`, `biburllcpenalty`) and use `\raggedright` (LTR) in the bibliography. Give long captions a short form, `\caption[short]{long}`. Rebuild until no overfull box is wider than 2 pt.

**LG-05 · major** — **Problem:** The front-matter lists show BiDi and spacing defects, on the first pages the grader reads. In the LOF/LOT, spaces after `\en{}`/`\ltr{}` are lost ("SMARTלהשקת", "AURAלחלון", "6חודשים", "150אלף"). Table 4.1 and Figure 4.1 entries have their word order jumbled, and LOF lines carry citation numbers ([7], [9], [10], [8]). The cause is in the class (the direction macros in moving arguments), so it affects both partners' captions. Separately, the flagship box on p. 14 prints the authors as "Robert Shoemaker ,Kapil Bawa" (comma on the wrong side). **Where:** `main.pdf` pp. 5–6 (front ד–ה) and body p. 14; `aura-report.cls` (`\en`, `\ltr`); `chapters/03-literature.tex` flagship box. **Concrete fix:** Make `\en`/`\ltr` robust (`\DeclareRobustCommand`) and keep the following space (`\xspace`, or end with `\ `). Give every caption that contains a `\cite` or a long English phrase a short optional argument without citations. Put each author list in one `\en{}`. Raise the class version and add a changelog line, then recompile `tests/bidi-test.tex` (as `CLAUDE.md` section 6 requires).

**LG-06 · major** — **Problem:** The README is stale and incomplete for a submission. The header still says "chapters not written yet". The chapter table still lists References as 3 pp. (actual: 6). The manual build mentions only `page_budget.py`, not the four figures that are actually used. There is no link to the final PDF and no description of the AI workflow (which agent did what, Gemini planning, the committee). **Where:** `README.md` header "Status", the parts table, "How to compile". **Concrete fix:** Update the status to "complete: 37-page body, 0 errors". Correct the pages column. List all four figure scripts, or say that `build.ps1` runs them all. Add a short "Workflow and agents" section and a link to `main.pdf` and `docs/committee/summary.md`.

**LG-07 · major** — **Problem:** The page budget is exceeded in the references: 6 pages (38–43) against the 3 in the booklet map and in the team's own plan. The numbered report is therefore 43 pp., not 40. The cause is the double line spacing (1.5 stretch) in the bibliography plus 54 entries, 38 of them long web URLs. **Where:** `main.pdf` pp. 38–43; `aura-report.cls` `\printreferences`. **Concrete fix:** Set the bibliography to single spacing with `\small` and break URLs (see LG-04). That alone should bring it to about 3–4 pp. Merge or drop thin web sources that duplicate a stronger one (e.g. two Makeupstore listings, the Bank of Israel home page).

**LG-08 · major** — **Problem:** The multi-agent method (9.4) was only partly used. Every chapter was written and self-checked by a single agent; no reviewer agent sent comments back to the writer before a push. The committee (prompt 16) runs after all eight chapters were pushed. `docs/committee/` does not yet exist in git, and prompt 16 still has the placeholder "(filled in after the merge)". **Where:** `prompts/04`–`15`, `prompts/16-expert-committee.md` (untracked). **Concrete fix:** Finish the loop the lecture describes: commit the committee files; apply the chosen fixes in a logged prompt (17+), with each fix traced to its finding ID; rebuild; and record in prompt 16/17 what changed. Optionally, run one reviewer pass on Raghad's chapters with her agent too, so both partners show the method.

Point [34] to the dated rate page. Get the full text of Bawa & Shoemaker (2004) through the university library, then check the method/limits paragraph against it.
